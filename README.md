# ⌚ ChronoX – Luxury Watches Responsive Landing Page

### SkillCraft Technology – Web Development Internship | Task 1

A modern, premium and fully responsive luxury watch landing page designed using HTML, CSS and JavaScript. ChronoX delivers an elegant digital experience with a sophisticated black-and-gold theme, stylish product showcases, interactive navigation and visually appealing sections.

## 📌 Project Overview

ChronoX is a luxury watch brand landing page created to demonstrate modern web development and UI design principles.

The website showcases premium watch collections through an elegant interface, featuring product cards, brand highlights, customer testimonials and engaging call-to-action sections.

The primary objective is to create a visually attractive, user-friendly and responsive landing page that provides a premium brand experience across different screen sizes.

## 🎯 Project Objectives

- Build a modern and responsive landing page.
- Create an elegant luxury brand identity.
- Implement interactive navigation using JavaScript.
- Showcase premium watch collections.
- Design attractive and reusable UI components.
- Ensure a smooth browsing experience across devices.

## ✨ Key Features

- **Premium UI Design:** Elegant black-and-gold color combination.
- **Responsive Navigation:** Mobile-friendly navigation menu.
- **Hero Section:** Attractive introduction with luxury watch imagery.
- **Featured Collection:** Product cards displaying watch images, names and prices.
- **Statistics Section:** Highlights customer reach and brand information.
- **Features Section:** Showcases product quality and premium materials.
- **Customer Testimonials:** Dedicated section for customer reviews.
- **Call-to-Action Section:** Engaging shopping and exploration buttons.
- **Smooth Scrolling:** Improved navigation experience.
- **Interactive Effects:** Hover animations and floating image animation.
- **Responsive Layout:** Optimized layouts for desktop, tablet and mobile screens.

## 📱 Responsive Design

The website uses CSS media queries to adapt its layout to different screen sizes.

- Desktop: Two-column hero section and four-column statistics layout.
- Tablet: Adjusted content arrangement and navigation.
- Mobile: Single-column hero layout and responsive navigation menu.
